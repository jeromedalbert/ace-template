# Acknowledgments

Thanks to Matt Brictson (https://github.com/mattbrictson) and Chris Oliver
(https://github.com/excid3) for creating their popular Rails application
templates. I used code from Matt's `rails-template` to configure source paths
for template URLs, and his newer `nextgen` project offered many interesting
ideas. I also drew inspiration from Chris' `gorails-app-template` for some of
the Bootstrap views.

Thanks to Piotr Murach (https://github.com/piotrmurach) for creating the TTY
toolkit gems. While I was not able to use the `tty-prompt` gem as is because it
does not yet support nested multiselects, I mimicked its appearance when
implementing interactive mode.
